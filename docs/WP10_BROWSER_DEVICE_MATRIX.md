# WP10 Browser / Device / Accessibility Matrix

Minimum coverage:
- Desktop Chrome: full core journey.
- Desktop Edge: full core journey.
- Desktop Firefox: critical smoke.
- Android-width mobile: search/filter/detail/sticky actions/forms.

- visible focus;
- modal focus trap and restoration;
- Escape/close;
- no keyboard traps;
- labelled form controls/validation;
- practical 44px+ mobile primary actions;
