# Highrise.pk

Pakistan's first Property & Construction Intelligence Ecosystem.

## Mission
Plot se possession tak, aur possession se lifetime maintenance tak — Sab Kuch Yahan.

## Platform Pillars
- **PROPERTY** — Find, verify, buy, sell and rent
- **SAFEDEAL** — Coordinate safer property transactions
- **BUILD** — Plan, estimate, design and monitor construction
- **PROCURE** — Compare materials and delivered costs
- **SERVICES** — Hire verified professionals and contractors
- **MAINTAIN** — Fix and protect homes and buildings

## Tech Stack
- Next.js 15.5.x (Pages Router)
- TypeScript 5.9 Strict
- MongoDB Atlas + Mongoose 7.8.x
- NextAuth v4 (JWT)
- Upstash Redis
- Tailwind CSS
- Cloudinary
